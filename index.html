CLI

⚡ Zero‑dependency CLI binary

Same engine, no GUI overhead — perfect for servers, CI, or headless automation.

Install via Cargo (recommended)

Requires Rust ≥ 1.78. Compiles a static binary for your host.

$ cargo install chimera-agent --locked

Or download a pre‑built binary

Grab the chimera-agent file from the latest release, make it executable and drop it in $PATH.

Quick start

# Show help\n$ chimera-agent --help\n\n# Run a DAG from a TOML config\n$ chimera-agent run --config ./my‑pipeline.toml\n\n# One‑shot LLM prompt (streaming)\n$ chimera-agent ask \"Summarise the last 5 commits\" --stream
